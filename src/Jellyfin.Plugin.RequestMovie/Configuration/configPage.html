Request Movie

Afisare cereri pe Samsung TV (optional)

IMPORTANT: Creeaza folderul pe server, adauga-l in Jellyfin Dashboard > Libraries ca biblioteca de tip Movies si abia apoi activeaza sincronizarea. Se genereaza doar filme placeholder .disc, care NU pot fi redate. Serialele nu sunt incluse. La indeplinirea sau stergerea cererii, placeholderul creat de plugin este eliminat la urmatoarea sincronizare.

Buton personalizat administrator (filme in asteptare)

Variabile disponibile: {title}, {year}, {tmdbId}, {imdbId}, {kind}, {requestId}. Valorile sunt codificate automat pentru URL. Foloseste doar adrese http:// sau https://. Lasa URL-ul gol pentru a ascunde butonul. Butonul apare exclusiv administratorilor, la filme cu status In asteptare.

Formularul este inclus in plugin. Deschide formularul de cereri.

Pentru afisare ca pagina in meniul principal pentru toti utilizatorii foloseste Plugin Pages 3.0+ sau extensia Custom Tabs. Nu folosi ruta veche #!/requestmovie.
